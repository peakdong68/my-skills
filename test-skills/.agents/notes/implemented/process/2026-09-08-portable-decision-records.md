# Agent Note: 决策管理资源与项目历史分离

Status: implemented

部分替代说明：固定分类、格式与工具的具体方案已由 [DSH 统一 Notes 决定](./2026-10-29-setup-planning-dsh-notes.md) 更新。可复用规则与项目历史分离、目标项目定制由目标项目拥有、重复 setup 不覆盖定制的理由仍有效。

## 问题

首次落实将 workflow、skills 等本仓库特征用作通用分类，混淆了可复用管理工具与项目历史。用户指出该设计无法直接服务其他业务项目。

## 决定

通用 Note 格式与工具由 `write-notes-like-deepseek` Skill 拥有。Setup 不再附带另一套 Notes 资源；项目记录保留在各自仓库，不随 Skill 安装复制。本仓库历史记录仍独立保留，目标项目已有有效记录体系时先检查其属主与迁移范围。

## 备选方案

放弃以本仓库技能与工作流划分类别的方式，它将项目特征变成了通用约束。保留本仓库历史，避免为了资源通用化删除已接受决定的依据。资源随现有 setup 选配，不新增必经技能或安装门禁。

## 后果

DSH Skill 是可复用规则源，项目指令只指向它并记录项目特有的 Notes 根选择。项目自行决定是否安装 Skill、配置 npm 命令或接入 CI；安装不会覆盖已有记录或授予批准与执行权限。

重复执行 Setup 默认复用既有项目选择；Notes 格式迁移需纳入明确授权的升级范围，逐条保留可验证的记录事实并修复引用。
