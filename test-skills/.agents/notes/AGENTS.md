# Agent Notes

The repository-wide Notes root is `.agents/notes/`; existing records are shared process and repository decisions. No per-context or shared subroots beyond this root are currently selected.

Follow the [write-agent-notes Skill](../skills/write-agent-notes/SKILL.md) for Note eligibility, fixed classes, format, lifecycle, alternatives and validation. Search existing records before creating a Note. Use `--root .agents/notes` when invoking a DSH command from the repository root. A future isolated context root requires an explicit project decision and an entry here; run its DSH commands with that selected root.

The project work item, review and authorization rules live in [root AGENTS.md](../../AGENTS.md). Keep those workflow facts in the work item; Notes record durable technical reasons and decisions.
